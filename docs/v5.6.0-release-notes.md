# AutoTuner v5.6.0

## Änderungen

- **MTP-Erkennung:** Ein vollständiger Tensor-Scan ohne MTP hat Vorrang vor
  einem irreführenden Dateinamen. Passende angehängte Heads und Legacy-Fallbacks
  bleiben nutzbar.
- **OCR:** GLM, Paddle und dots verwenden die jeweiligen offiziellen
  Aufgaben-Prompts. Der gemeinsame Dokument-Workflow wurde real geprüft.
- **Bild + DFlash2:** Auf lokal qualifiziertem llama.cpp **b11319** wieder
  freigegeben; tatsächlich getestete HIP/Vulkan-Bildanfragen und akzeptierte
  Draft-Tokens. Die Schutzsperre für **b10896–b11318** bleibt bestehen.
- **Vulkan-MoE auf RDNA4:** Ein optionaler, exakt b11319-gebundener Build behebt
  den gemessenen Durchsatzverlust auf R9700/RX 9070 XT. Kein globaler Revert,
  kein Ersatz der Stock-Builds und keine automatische Einstellungsänderung.
  [Buildanleitung und Grenzen](https://github.com/DaWasteh/Auto-Tuner/blob/main/docs/rdna4-moe-workaround.md).

## Download

| System | Paket |
|---|---|
| Windows 10/11 x64 | `AutoTuner-Windows-x64.zip` — entpacken, AutoTuner.exe starten |
| Linux x64 | `AutoTuner-Linux-x64.zip` — entpacken, `chmod +x AutoTuner-Linux` |
| macOS Apple Silicon | `AutoTuner-macOS-arm64.zip` |

Der Update-Button verwendet das passende Paket; bestehende Einstellungen
bleiben erhalten. macOS: Community-Build ohne Apple-Notarisierung; bei Bedarf
Finder-Rechtsklick → Öffnen bzw. Datenschutz & Sicherheit → Dennoch öffnen.
