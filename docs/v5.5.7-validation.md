## CPU tiled matmul (PR #27851)

`llama-bench -dev none -ngl 0 -p 512`, Qwen3.8-27B-UD-IQ4_XS (13.3 GiB),
same Vulkan-recipe binaries, CPU only:

| Threads | b11160 pp512 | b11195 pp512 | Δ |
|---:|---:|---:|---:|
| 8 | 30.1 | 22.1 | −27 % |
| 16 (ABBA, two runs each) | 40.3 | 33.9 | −16 % |
| 24 | 50.1 | 43.2 | −14 % |

tg32 stays at 5.2 tok/s. `GGML_CPU_TILED_MM=0` on b11195 gives 13.6 tok/s at
16 threads, i.e. the removed `iqp` path was what made b11160 faster; the
switch is no workaround. Only CPU-only prompt processing on this AVX2 CPU
is affected; the GPU and hybrid plans above are not.
